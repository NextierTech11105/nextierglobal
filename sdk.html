SDK

One file, no dependencies, full TypeScript types. Runs anywhere fetch does: Node 18+, Deno, Bun and edge runtimes. Server-side only, because your key is a secret.

Install

Download the two files into your project. An npm package is next.

curl -O https://www.nextierglobal.ai/sdk/nextier.mjs
curl -O https://www.nextierglobal.ai/sdk/nextier.d.ts

nextier.mjs · nextier.d.ts

Use

import { Nextier } from "./nextier.mjs";

const nx = new Nextier({ apiKey: process.env.NEXTIER_API_KEY });

// Detect
const { signals } = await nx.signals.netNew({ since: "2026-10-01", family: "distress" });

// Classify + prioritize: born tagged, then keep it aligned
await nx.leads.autotag({ leadIds: signals.map((s) => s.lead_id).filter(Boolean) });

// Execute: stage the initial outreach for a person to approve
const ready = [];
for await (const lead of nx.leads.listAll({ tag: "EXECUTION_READY" })) ready.push(lead.id);
const block = await nx.push.initialSms({ leadIds: ready, name: "Net-new distress" });
console.log("Approve it here:", block.launchUrl);

Paging

listAll walks every page at the API’s 200-per-page maximum and yields one lead at a time.

let n = 0;
for await (const lead of nx.leads.listAll({ tag: "HIGH_PURSUIT" })) n++;
console.log(n, "high-pursuit leads");

Errors and retries

Every failure throws a NextierError with status and the API’s error body. Reads are retried with exponential backoff on 429, 5xx and network errors. Pushes are never retried automatically, so nothing is ever staged twice.

import { Nextier, NextierError } from "./nextier.mjs";

try {
  await nx.leads.update({ leadIds, set: { priority: "high" } });
} catch (e) {
  if (e instanceof NextierError && e.status === 401) console.error(e.body.hint);
  else throw e;
}
