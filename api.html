API

The Data Engine API is JSON over HTTPS. It is read-first: reads are scoped to your workspace, writes only touch descriptive data, and pushes stage work for a person to approve in nxtier.ai.

Base URL

https://www.nxtier.ai/api/data-engine/v1

Authentication

Send your Data Engine key on every request, in either header. Keys look like de_live_…, are issued per workspace and shown once. Only a SHA-256 hash is stored. Every call is metered on the key, and a revoked key stops working immediately. Request a key.

x-api-key: de_live_…
# or
Authorization: Bearer de_live_…

The key decides the workspace. Every query and write is pinned to it, and there is no header that switches workspaces. Keep the key server-side; never ship it to a browser or a mobile app.

Errors

StatusMeaningBody
401Missing, unknown or revoked key{"error":"Invalid or missing API key.","hint":"…"}
400Invalid request, e.g. leadIds missing or no allowed field to set{"error":"leadIds is required"}
4xxA push refused for a stated reason{"error":"…"}
500Server error. Safe to retry reads with backoff{"error":"…"}

Limits

  • GET /leads: up to 200 per page. Use offset to page.
  • GET /signals/net-new: up to 5,000 per call.
  • POST /leads/autotag without leadIds: up to 50,000 leads per run (default 5,000).
  • POST /push/dialer: up to 500 rows per call.
  • Every call is metered on your key. Batch bulk work rather than sending one lead per call.

POST/api/data-engine/v1/leads/autotagClassify + Prioritize

Label at origin (auto-tagging)

The auto-tagging rule. mode "origin" (default) stamps static origin facts plus dynamic labels, so a lead is born tagged. mode "dynamic" re-stamps only the dynamic labels and preserves the static ones: run it on every change (enrichment, scrub, signal update) so alignment never drifts. Omit leadIds to tag the whole workspace up to limit.

Body

NameTypeRequiredDefaultNotes
leadIdsstring[]nowhole workspaceLeads to tag. Omit to run across the workspace.
limitintegerno5000When leadIds is omitted: how many leads. Capped at 50,000.
mode"origin" | "dynamic"no"origin"origin = static + dynamic. dynamic = re-stamp dynamic only.

Request

curl -X POST https://www.nxtier.ai/api/data-engine/v1/leads/autotag \
  -H "x-api-key: $NEXTIER_API_KEY" \
  -H "content-type: application/json" \
  -d '{"mode":"dynamic","limit":5000}'
// born tagged
await nx.leads.autotag({ leadIds: newIds });

// after every change: re-stamp dynamic labels only
await nx.leads.autotag({ mode: "dynamic" });

Response

{
  "ok": true,
  "tagged": 4820,
  "mode": "dynamic",
  "breakdown": {
    "HIGH_PURSUIT": 312,
    "MEDIUM_PURSUIT": 1104,
    "HIGH_CONVERGENCE": 87,
    "HIGH_CONTACTABILITY": 2210,

    "SUPPRESS": 41
  }
}

POST/api/data-engine/v1/leads/updateClassify

Update leads in bulk

Set a safe list of fields on many leads: priority, score, notes, campaign_name. Anything else is rejected. Journey, compliance and state fields belong to the disposition router and cannot be set from the API.

Body

NameTypeRequiredDefaultNotes
leadIdsstring[]yes—Leads to change.
setobjectyes—{ priority?: string, score?: integer, notes?: string, campaign_name?: string }

Request

curl -X POST https://www.nxtier.ai/api/data-engine/v1/leads/update \
  -H "x-api-key: $NEXTIER_API_KEY" \
  -H "content-type: application/json" \
  -d '{"leadIds":["lead_01J…"],"set":{"priority":"high","notes":"Owner asked for a call after 5"}}'
const r = await nx.leads.update({ leadIds, set: { priority: "high" } });
if (r.rejectedColumns) console.warn("not allowed:", r.rejectedColumns);

POST/api/data-engine/v1/push/dialerExecute

Push leads to the dialer

Bring your own rows or route existing leads onto the operator's power dialer. Raw rows are upserted into your workspace first, de-duplicated by phone. Opted-out, suppressed and do-not-call leads are never queued. Nothing is dialed until an operator starts the dialer.

Body

NameTypeRequiredDefaultNotes
leadsDialerLeadRow[]one of—Up to 500 rows per call: firstName, lastName or name, phone, email, address, city, state, zip, notes, phoneType, dnc, tcpa.
leadIdsstring[]one of—Leads that already exist in your workspace.

curl -X POST https://www.nxtier.ai/api/data-engine/v1/push/dialer \
  -H "x-api-key: $NEXTIER_API_KEY" \
  -H "content-type: application/json" \
  -d '{"leads":[{"name":"Jordan Example","phone":"+15165550142","city":"Riverhead","state":"NY"}]}'
