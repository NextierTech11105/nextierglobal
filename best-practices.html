Best practices

This assumes you already have a working request. It covers how to make it better.

Start with the smallest useful request

Net-new signals for your workspace, last 30 days by default:

curl "https://www.nxtier.ai/api/data-engine/v1/signals/net-new" \
  -H "x-api-key: $NEXTIER_API_KEY"
const { signals } = await nx.signals.netNew();

Add a parameter only when you need it:

ParameterAdd it when
sinceYou want a window other than the last 30 days
familyYou work one signal family, such as distress
limitYou want fewer rows. Up to 5,000

Read the response in layers

{
  "event_type": "NET_NEW_PRE_FORECLOSURE",
  "field_name": "pre_foreclosure",
  "lead_id": "lead_01J…",
  "detected_at": "2026-10-24T11:02:51.000Z",
  "signal_family": "distress",
  "truth_class": "verified_net_new"
}
  • event_type says what happened. detected_at says when it was found.
  • truth_class verified_net_new means a first detection or a step up the ladder, not an old record seen again.
  • lead_id can be null. Only leads can be labeled or staged, so check it first.

Label at origin, then keep labels aligned

Run mode: "origin" once when leads arrive. After every enrichment, scrub or signal update, run mode: "dynamic". It re-stamps current-state labels and leaves origin labels alone.

await nx.leads.autotag({ leadIds: newIds });   // born tagged
await nx.leads.autotag({ mode: "dynamic" });   // after every change

Stage, never send

Push endpoints hand work to people. Each one returns a launchUrl or dialerUrl and counts the leads it skipped. Ineligible leads are skipped, never queued. Show the person the link. Don't report a push as sent.

Budget your calls

  • Every call is metered on your key. Batch bulk work.
  • listAll pages at 200, the maximum.
  • Reads are safe to retry with backoff on 429 and 5xx. Pushes are not.
  • Record the request and the count it returned, so a regression can be reproduced.

Common mistakes

Instead ofUse
POST /leads/score in new codePOST /leads/autotag. Same rule, same body.
Setting status, stage or journey through /leads/updateThe disposition flow in nxtier.ai. The API rejects those fields.
Removing journey or compliance tags with /leads/tagNothing. That endpoint only touches your own tags.
Retrying a push after a timeoutRead the launch page or GET /leads first. The SDK never retries a push.
Expecting /push/initial-sms to sendIt stages a held block. A person presses Send.
One lead per callBatches: 200 leads per page, 500 rows per dialer push.
A header to switch workspaceThat workspace's own key.
The key in a browser or a mobile appYour server. The key is a secret.
