Quickstart

Five calls, from a key to a staged block a person approves.

1 · Get a key

Keys look like de_live_…. Each one opens one workspace and is shown once. Request a key.

export NEXTIER_API_KEY="de_live_…"

2 · Check it

curl https://www.nxtier.ai/api/data-engine/v1 \
  -H "x-api-key: $NEXTIER_API_KEY"
const info = await nx.info();
console.log(info.teamId, Object.keys(info.endpoints));

3 · Pull net-new signals

What changed in your territory, newest first.

curl "https://www.nxtier.ai/api/data-engine/v1/signals/net-new?since=2026-10-01&family=distress&limit=500" \
  -H "x-api-key: $NEXTIER_API_KEY"
const { signals } = await nx.signals.netNew({ since: "2026-10-01", family: "distress" });

4 · Label them

Stamp origin and dynamic labels so the next list sorts itself into pursuit levels.

curl -X POST https://www.nxtier.ai/api/data-engine/v1/leads/autotag \
  -H "x-api-key: $NEXTIER_API_KEY" \
  -H "content-type: application/json" \
  -d '{"mode":"dynamic","limit":5000}'
// born tagged
await nx.leads.autotag({ leadIds: newIds });

// after every change: re-stamp dynamic labels only
await nx.leads.autotag({ mode: "dynamic" });

5 · Stage the first outreach

This stages a held block. It sends nothing. A person opens launchUrl and presses Send.

curl -X POST https://www.nxtier.ai/api/data-engine/v1/push/initial-sms \
  -H "x-api-key: $NEXTIER_API_KEY" \
  -H "content-type: application/json" \
  -d '{"leadIds":["lead_01J…"],"name":"Riverhead · pre-foreclosure","signalType":"pre_foreclosure"}'
const block = await nx.push.initialSms({ leadIds, name: "Riverhead · pre-foreclosure" });
console.log(block.blockId, block.launchUrl); // a person approves it there
